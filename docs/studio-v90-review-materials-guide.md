# 案例库和工程背景：直接填写，不用编辑格式

在“工程配置”页面点击 **案例库与工程背景** 即可。没有工程、没有保存扫描配置时也能使用；“OpenCode 复核”页面也提供此入口。

**资料位置固定：当前工具的 `config/concurrency_cases.md`、`config/review_context.md`。** 页面没有外部路径、来源选择或导入功能。两份文件供所有工程的新任务共用，切换工程前请核对背景。

## 编辑工程背景

选择 **工程背景（可留空）**，在文本框直接填写工程说明，点击 **保存工程背景**。无需填写标题或 Markdown 标记，程序自动生成正文。

没有补充说明时直接留空保存。原文件保存为空文件，表示不提供额外背景，不阻止扫描或 OpenCode 复核。模板注释不会显示为待填写的实际背景。

## 编辑案例

左侧可按名称或编号搜索案例。选择一条后直接修改文本框，点击 **保存当前案例**。

新增时点击 **新增案例**，填写 **案例名称**、**问题描述** 即可。未填写的分类标为“待分类”，名称自动成为检索线索，不会凭空标成已确认。来源、代码示例、发生过程和排查方法按需展开填写。编号、标题层级和代码围栏由程序生成；代码直接粘贴到“代码示例”。未知事实可写明“待核实”，不要写成已经确认。

修改一条案例不会重新格式化整本案例库，其余原文、来源说明、自定义字段和后续模板保留。原有重复编号、未闭合代码段等不能安全改写的条目会提示并保留原文。

## 保存与生效

- 保存立即修改上述 config 原文件，下一次新任务会冻结新内容。已启动任务及其恢复使用原快照，编辑不会改变正在复核的输入；原快照缺失时会拒绝用当前资料冒充旧版本。
- 可以跨标签页和案例保留未保存草稿；关闭或重新读取前会提醒。其他窗口修改了原文件时，本窗口保存会报冲突，草稿不会被自动清空。
- 保存前在独立数据根 `settings/review-materials-history` 保留原文和拟保存版本。它们是恢复备份，不会成为其它资料来源。旧版本的工程副本和外部绑定未删除，但新任务只读取 config 原文件。
- config 目录不可写时会提示并保留草稿。请将完整工具放在可写目录后重试；不会悄悄改存到外部路径。
