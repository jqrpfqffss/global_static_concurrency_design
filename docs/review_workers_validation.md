# workers 持续补位调度验证

验证于 2026-10-19 开始，持续至 2026-10-20（Asia/Shanghai）。本次编码由 Codex 直接完成，真实模型调用仅用于执行产品自身的只读 OpenCode 复核。

## 最终行为

复核并发配置仅保留 `review.workers`，范围仍为 1–8，默认 1。已删除配置中的 `max_items`、两个初始化模板中的对应字段、运行期读取与校验、分批调度和批次进度信息，并更新使用文档及测试。

`workers: 3` 使用一个覆盖全部目标的线程池，最多同时处理 3 个变量。一个变量完成、复用缓存或结束技术失败处理后，空闲线程直接领取下一项。报告更新仍由主线程按完成顺序写入；报告写入不会阻止空闲复核线程领取任务。每个变量继续使用独立的只读会话、证据包与结果收据。

中断或结果回调异常退出时，取消尚未开始的任务，避免线程池退出期间继续启动后续复核；已经运行的任务按既有行为结束。

`run`、`review`、`review-failed` 共用这一调度过程，原有缓存、强制重新复核、仅重试技术失败项的语义保持一致。
