# 独立浏览器业务使用检查

本页保留首轮独立检查的真实操作，不代表后来各版均重跑本流程；最新最终成品及验证继承边界见[当前 V9 验收](continuation-final-v9.md)。

检查者未实现 Studio 界面，开始时没有阅读 `App.vue`、CSS 或组件实现来安排按钮顺序。业务目标是从全新数据根打开示例、找到并发证据及源码、签署测试人工记录、退出浏览器后继续剩余工作。先通过实际画面寻找入口，再按界面反馈操作。本记录是这条业务路径的独立检查，不替代真实用户工程构建/扫描验收。

## 环境与启动

- Windows，当前工作区源码，`py -3.10` / Python 3.10.11。
- 全新数据根 `H:/ECRA-quality-20261108/independent-ui`，启动前不存在；没有复制/注入旧人工状态。
- 启动命令：`py -3.10 run_ecra.py ui --data-root H:/ECRA-quality-20261108/independent-ui --port 0 --no-browser --session-file H:/ECRA-quality-20261108/independent-ui-session.json`。
- Chrome headed，Playwright CLI 会话 `ecra-quality-independent`；持久浏览器配置 `H:/ECRA-quality-20261108/independent-browser`。浏览器使用本次启动器提供的 URL，不手工构造认证信息。会话凭据已从本轮证据日志隐藏。
- 实测浏览器视口为 **1366×768** 与 **1920×1080**。这里改变的是浏览器视口；没有将它表述为浏览器页面缩放或 Windows 显示缩放。两种缩放未在本职责额外验证。
