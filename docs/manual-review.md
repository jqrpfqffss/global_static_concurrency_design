# 人工并发风险确认与断点续审

人工确认是独立审计维度，不修改静态分类、OpenCode 答案、访问记录、冲突证据或调用链。

## Windows PowerShell 操作

使用工具侧 `config/semantics.yaml` 中的工程配置：

```powershell
py -3.10 .\run_ecra.py run
py -3.10 .\run_ecra.py serve
```

`serve` 只读取已有扫描，不启动 Clang、构建或 OpenCode。默认绑定 `127.0.0.1` 的空闲端口并打开浏览器。固定端口或不自动打开浏览器：

升级版本后，如果旧扫描的分析引擎指纹不匹配，需要先执行一次 `run`；服务不会自动扫描或绕过旧结果校验。

```powershell
py -3.10 .\run_ecra.py serve --port 8876 --no-browser
```

Portable 在解压目录执行：

```powershell
.\ecra.cmd run
.\ecra.cmd serve
```

指定其他工程和配置时推荐绝对路径：

```powershell
py -3.10 .\run_ecra.py serve --project D:\Firmware\Board --config H:\ECRA\config\semantics.yaml
```

顶部显示总数、有风险、无风险、待确认、需重新确认和完成率。“继续确认”按变量身份定位剩余队列，支持跨分页。人工栏目沿用原有搜索、筛选、文件过滤和打印。

先查看变量原始源码、访问和调用链，再点击“确认有风险”或“确认无风险”。无风险必须填写依据；修改、重新确认和撤销必须说明原因。可以填写确认人、实际触发条件和备注。只有数据库提交成功，页面才更新状态。模型结论与人工判断不一致时显示分歧提示。

关闭页面、停止服务后，下次执行 `serve` 即可继续。其他页面修改过记录时，旧修订提交被拒绝；使用“重新加载人工状态”后重新核对。

仅重新生成报告、重新复核或重试技术失败：

```powershell
py -3.10 .\run_ecra.py report
py -3.10 .\run_ecra.py review
py -3.10 .\run_ecra.py review-failed
```

“查看此变量历史”和“查看全部历史（含范围外变量）”显示修改、撤销、失效与导入记录。导出包含当前记录与历史；导入验证项目身份、格式、证据和修订号，冲突时整批回滚。

双击 `index.html` 仍可离线搜索、查看证据和打印。人工按钮禁用并提示启动服务，离线页面不宣称已保存人工结论。

## 数据与备份

数据库位于被扫描工程的 `<analysis.output_dir>/manual_review/manual_review.sqlite3`，默认 `.ecra/manual_review/manual_review.sqlite3`，不依赖浏览器缓存。

SQLite 使用 WAL、FULL 同步、事务与每变量修订号。`current_review` 以 `(project_id, variable_id)` 为主键，保存当前完整记录的 JSON payload 和修订号；`history` 以自增事件 ID 为主键，以 `(project_id, variable_id, revision)` 唯一约束保存前后状态、证据摘要、依据、确认人和时间。字段包含变量名称、文件位置、范围、确认时间、更新时间等。历史与当前状态在同一事务提交。

扫描重建 facts 数据和 HTML 时保留人工目录；扫描快照通过 SQLite 在线备份 API 保存一致副本，包括已提交的 WAL 页面，不直接复制正在使用的数据库。日常备份可点击“导出记录与历史”。服务运行时不要只复制主 `.sqlite3` 文件而遗漏 WAL。

默认项目身份绑定规范化工程根目录。完整目录迁移会改变项目身份；本版不自动接受其他路径的项目导入，避免同名项目之间错误继承。迁移前保留原始数据库与导出文件。

## 身份、范围与有效性

变量身份使用 `SHA256(storage-v1, symbol_id)`。原有 symbol_id 包括 Clang USR、内部链接的 TU 前缀、函数 static 的所属函数与同名声明序号、结构体字段路径和数组元素路径。finding 是规则及上下文形成的候选，不能当变量身份。多个 finding 只生成一次人工任务；容器、非存储项、独立缺口、构建范围外声明、静态安全与共享无需复核项不进入工作量。

证据指纹独立于整体扫描指纹，包含存储对象、访问与 RMW、保护、别名、相关调用分量、上下文、全局未知事实、真实编译参数、配置、输入清单、静态分析引擎及通过收据校验的模型结论。显示位置、执行时间和缓存键不作为证据身份。源码保留声明、预处理指令、相关函数实现、所有头文件和其他构建输入；只在边界明确时剔除无关函数实现，否则退回完整文件摘要。

相同证据保留确认人、时间和依据。相关代码、调用图、保护、优先级、宏、模型结论等变化后，读取人工状态时自动追加失效历史并转为“需重新确认”。失效状态不因代码改回旧版自动恢复。输入校验失败、解析不完整或扫描期间源码改变时暂停提交，旧结论不计为有效完成。扫描/复核占锁期间暂停操作；相同证据的正常重扫不因临时锁永久清空进度。

范围外或已删除变量保留数据库与历史，不计当前进度；消失不代表修复。

保守边界：头文件、编译输入、全局配置或未知事实变化可能使多个变量重新确认。本版没有 Git 差异扫描，不承诺对间接访问或外部行为精确缩小影响范围。每次写入重新验证扫描输入，响应时间受工程规模和磁盘影响。

## 本地接口与安全

- `GET /api/state`：当前范围、状态、进度、修订号及会话令牌。
- `POST /api/decision`：确认、修改、撤销；校验 ID、证据、范围、报告指纹、修订号与依据。
- `GET /api/history?variable_id=...`：单变量历史；省略参数返回全部历史。
- `GET /api/export`、`POST /api/import`：JSON 导出/事务导入。

写请求必须具有本服务 Origin 和 `X-ECRA-Token`。服务校验 Host、Fetch Metadata、报告和证据，仅提供固定报告文件，拒绝目录遍历与任意磁盘路径。备注与历史通过文本节点展示。请求上限 8 MiB，超大归档暂不支持分批导入。
