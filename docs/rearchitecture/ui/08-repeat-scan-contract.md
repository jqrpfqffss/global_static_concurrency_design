# 向导启动与日常重扫实施规格

继承冻结四步向导和首页布局，不增加导航。向导检查并保存独立profile后，在第4步提供“开始此配置扫描”；修改高级YAML后先重新检查保存，禁止用未保存文本冒充已提交配置。保留原“保存独立配置”动作，开始按钮调用同一个真实POST /tasks合同，带project_id/profile_id/revision，成功收到任务身份后进入任务中心并定位该任务。保存、检查和启动各自显示真实错误，不伪造扫描成功。

首页当前本机扫描存在相同project_id/profile_id的已保存配置时，显示当前保存版本的短SHA和“按此配置重新扫描”，一次点击提交真实扫描任务。明确采用当前已保存配置，不能将已修改配置说成原扫描字节；旧结果不覆盖，新任务独立发布。离线包只有归档能力，缺本机profile时不补造配置/不显示可执行重扫。原source/输入门禁与dirty阻断保持，TaskManager仍检查配置、资源租约和实际扫描输入。

默认自动预算与任务中心一致；自定义预算可先进入任务中心调整。收到真实任务ID后才导航；TaskCenter通过该ID打开详情，不能默认展示别的历史任务。API拒绝旧revision或预算占用时，当前归档继续可打开。验收需实际四步保存→启动→完成、首页同profile再启动→新扫描发布，检查原归档SHA、人工事件不变，固件与.git完整清单不变；另验未保存YAML不可启动、离线缺profile不冒充可重扫。该规格不构成U01/U02/U06全部通过。
