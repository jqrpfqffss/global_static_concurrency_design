# GUI数据目录选择合同

2026-11-02，实施前冻结，继承设置页“独立数据根”面板及现有只读目录选择器，不增加一级导航。此项关闭普通用户选择启动数据位置的CLI缺口；完整数据根搬迁仍独立待验。

| 区域 | 明确行为 |
|---|---|
| 当前使用位置 | 显示当前绝对路径和来源：启动参数、ECRA_DATA_ROOT、GUI保存的默认值或系统默认。 |
| 下次默认位置 | 文本路径+“浏览数据目录”，普通用户可以选空目录/已登记Studio数据根。先“检查数据目录”，通过后才有“保存为下次启动目录”主要动作。改变路径即废弃旧检查。 |
| 生效说明 | 保存成功后明确“关闭软件后重新双击ECRA.cmd生效”。当前窗口、运行中的任务和当前数据根继续使用原位置。旧扫描、人工记录和工程配置保留在原根；打开另一数据根不声称已搬迁数据。 |
| 覆盖来源 | 优先级为启动参数 > ECRA_DATA_ROOT > GUI默认 > 系统默认。显式参数/环境变量生效时，提示已保存默认值不会覆盖它们。 |
| 已有结果 | 指向已登记Studio根后，重启应看到原扫描和人工事件；空根首次界面明确未接入。旧.ecra/workspace必须走数据与共享的迁移入口。 |
| 错误 | 相对路径、盘根、程序/已知固件目录、当前根父子目录、链接/Junction、其他非空目录、不可写位置拒绝；失败不改默认值和任何静态/人工记录。 |
| 损坏设置 | 保留原始字节并显示恢复警告；默认启动可进入系统默认目录恢复设置，不能悄悄把空目录当成原历史。修复保存须明确同意备份损坏设置。 |

稳定偏好位于用户ECRAStudio设置位置，独立于程序包和可更换的数据根；Windows为%LOCALAPPDATA%/ECRAStudio/preferences.json。仍由WorkspaceResolver的user_data_root/studio_data_root解析与边界检查，禁止第二套工程workspace解析。仅本地保存，不修改全局环境变量、固件或程序包。

| API | 合同 |
|---|---|
| GET /api/settings/data-root | 当前路径/来源、保存默认值、偏好文件revision、恢复警告。 |
| POST /api/settings/data-root/preview | 只读检查目标归属/边界，返回目标路径/空或已有根/计划摘要；不写目标、不切换服务。 |
| PUT /api/settings/data-root | 按预览摘要与偏好revision重检；只在明确选择后检查目标可写；原偏好备份到内容寻址文件，再原子保存。并发冲突返回409，不最后写入覆盖。 |

验收必须包括实际服务保存、关闭、无--data-root再次启动、读取正确根与旧人工事件；独立默认用户位置，避免改动实际用户偏好。还需验证中文空格路径/程序升级模拟、显式覆盖优先级、错误/链接/固件拒绝且字节不变、并发旧revision拒绝、损坏偏好可恢复。不是全量根搬迁、第二物理电脑或G8干净机验收。
