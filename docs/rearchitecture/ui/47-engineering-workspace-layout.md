- 正文14–16px，常规数据行36–44px。顶部身份栏56–64px，默认导航216–240px，小屏可收起。页面主要空间用于当前任务，不靠浏览器缩小或隐藏未知信息通过检查。
- 工作台使用父级剩余空间布局；列表、证据各一个主要纵向滚动容器。表单页面自然滚动并固定必要操作。禁止在同一阅读链叠加多个固定高度小框。
- 大标题、计数、Diff摘要改为紧凑工具栏；复杂筛选和完整Diff证据用可放大专用对话框。关键失败/未知/冲突可见，详细解释可展开，完整字段继续可读。
