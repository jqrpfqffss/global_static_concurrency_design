# 设计 token（冻结 v1）

| token | 值 | 用途 |
|---|---|---|
| sidebar | #17283d | 低饱和深侧栏 |
| background | #f3f5f9 | 主区 |
| surface | #ffffff | 表单/证据 |
| text | #22344d | 主要文字 |
| muted | #667894 | 次要文字 |
| border | #d9e1ed | 分组/焦点之外边界 |
| primary | #245edb | 唯一主要动作 |
| danger | #be3043 | 风险，伴随文字 |
| suspect | #a96812 | 疑似，伴随文字 |
| unknown | #5b6f87 | 未知，伴随文字 |
| safe | #24775e | 已证明/人工无风险各自标来源 |
| spacing | 8/16/24/32px | 8px基础体系 |
| body | Segoe UI/Microsoft YaHei/sans-serif 14px | 浏览器离线系统字体 |
| title | 24px/600 | 页面标题 |
| row | 40px minimum | 多行名称自动增长 |
| source | Consolas/monospace 13px | 可单独调字号 |
| focus | 2px solid #245edb，offset2px | 全键盘焦点 |

不使用CDN、远程字体、渐变、无意义动画。200%DPI保留主动作与搜索，不截断结论语义。强主按钮同屏最多一个。
