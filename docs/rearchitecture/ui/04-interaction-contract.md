# 交互合同

| 路由 | 入口/返回 | 真实读写合同 | 错误/完成语义 |
|---|---|---|---|
| /overview | 默认；从各页返回 | 查询当前scan摘要与同口径过滤 | 无scan显示未扫描，不显示0风险 |
| /projects | 首次/工程配置 | profile独立保存、校验、版本化 | 字段+原因+修复例；高级字段保留 |
| /tasks | 扫描/状态栏 | 受监督任务状态/TU提交/资源/日志 | 只有STATIC_VALIDATED可打开新静态结果 |
| /variables | 卡片/搜索/诊断 | QueryService分页/过滤/完整证据段 | 保留筛选/对象/分栏；总数+游标 |
| /coverage | 概览缺口 | 同scan TU和相关缺口 | 不以TU比例替代变量覆盖 |
| /opencode | 导航/详情 | 完整EvidenceProvider/合法复核队列 | TECH_FAILED与静态分类正交 |
| /reviews | 概览继续/导航 | 独立reviews.db事件事务 | 提交后才“已保存”；无风险需依据 |
| /history | scan选择 | 不可变快照列表/可比性 | 本轮未观察到不等于已修复 |
| /sharing | 首次导入/历史导出 | 一致快照/安全包/幂等事件 | 失败不污染已有scan |
| /settings | 侧栏底部 | 独立数据根/资源预算 | 路径边界预检后原子保存 |

Ctrl+F聚焦变量搜索；Esc关闭弹层并还原焦点；Tab可离开详情；复制完整名称/引用。筛选改变重置分页但不清空高级条件。保存进行中禁止重复提交；失败保留输入。撤销以新事件引用原事件，不删除历史。

未实现的动作不注册为可点主按钮。可执行样机仅可执行已落地的真实读取/写入，未落地能力显示状态说明。界面显示不可信源码/备注只能文本，不用v-html。
