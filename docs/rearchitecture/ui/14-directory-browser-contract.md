# 工程与范围目录选择合同（编码前冻结）

保持既定四步与普通路径输入。在第1步固件路径旁提供“选择固件目录”，第3步include/exclude旁提供“从目录树纳入/排除”。使用本地Studio真实目录浏览对话框，允许浏览当前分支、父目录和本机驱动器；不引入新导航，不上传固件文件给浏览器，不自动创建目录/修改固件。

1. 对话框每次仅读取当前一级的真实目录元数据，不读取源码内容，不运行工程脚本。按名称稳定排序并分页（50项、服务端上限100），游标翻页能到全部目录，不静默top-N。浏览器只保留当前页与导航路径；搜索仅匹配当前层，明确说明，不伪称递归全工程搜索。
2. 固件选择可从输入的绝对目录或本机驱动器开始；范围选择必须绑定已填写工程根，只能进入其内部，不能借父目录/路径文本/链接跳到外部。链接、Junction或其他重解析项不跟随，显示不可选择原因。不存在/无权限/非目录/列举期间目录变化均有真实错误或告警，保留路径以便修复。
3. 选择固件目录只更新表单，不代表真实构建参数已验证；改变路径不启动扫描。范围选择写入相对工程路径，保留逗号和空格，其他目录条目原样保留。选择根表示“.”，说明此范围涵盖全部；排除仅影响变量清单，仍参与调用恢复。
4. 弹层有明确当前目录、返回父目录/驱动器、进入子目录、前后页、使用此目录和取消。取消/ESC不修改表单。使用现有令牌与按钮层级；1366×768下路径、主要动作可见，列表内部滚动，键盘可操作。原文配置同步/备份/检查/保存规则保持不变。
5. 本机回环API沿用会话令牌/Origin/Host门禁；选择接口只读，调用后原目录文件内容、Git元数据和mtime不得变化。目录观察不等于扫描输入快照，不能据此宣称U03/只读挂载或H2全部通过。
