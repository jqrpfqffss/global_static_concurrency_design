# U21 缺证据旧数据的降级查看合同（实施前）

完整facts/report与归属记录匹配时继续原来的完整只读转换，不改变旧字段、顺序、校验或人工历史。已知归属冲突、路径链接、活动WAL/锁继续拒绝。

新增显式选择“证据不全时只保存原文件，按未验证归档查看”，默认关闭。用户先选择原目录和声明的原工程路径，预览必须列出缺少的事实/报告/身份，不用当前固件补造它们；确认迁移后逐字节捕获所有现存文件、完整SHA校验、生成标准协议归档。原数据不改动、不删除，旧数据库/HTML/脚本均只作为不可信原字节。

缺证据分支只创建明确标记UNVERIFIED的导航容器，不从残缺报告推导canonical变量/访问/SAFE，也不把旧人工/AI文本当可信当前决定。全部原字节以审计索引/CAS保留，可分页查看，支持标准包往返和重复导入。新容器没有可确认变量；后端拒绝把它写成当前人工结论或重新复核。归档模式必须显示“未恢复可信静态证据；零可核验对象不等于零风险”，提供查看原件的实际按钮。

仍用同一LegacyArchive、MigrationJobs、EvidenceProvider和标准归档协议，不增加另一套旧库执行器。命令/脚本/HTML不执行，未知字节以文本或十六进制展示。完整输入存在但检查点哈希不匹配继续失败，不悄悄退化为看似完整的结果。正式扫描消费者与分析算法不受本项修改。

验收需包括缺facts、缺report、缺身份、错误已知归属、活动WAL、原件字节/mtime不变、恶意HTML仅文本、旧确认不继承、标准包往返后全部原件不丢、重复/中断/损坏保护，以及真实Chrome操作和截图。大型双旧数据转换、物理第二机仍单独待验，不能用小归档替代。
