# 精确线框（冻结 v1）

1600×900/1366×768，8px 网格。侧栏232px、顶栏60px、页面padding24px、区块gap16px。≤1100 CSS px侧栏收起为可键盘切换导航；≤850px证据单栏并提供返回列表。主区域min-width:0，长名称/路径可换行。

```text
┌─232px────┬────────顶栏60px：项目 / 核心 / profile / scan / 有效性────────┐
│ECRA      │ 标题 + 身份/范围                         唯一主动作         │
│九导航    │ [静态疑似] [无法判断] [本构建已证明安全] [人工待确认]       │
│          │ ┌优先处理（65%）─────────┐ ┌覆盖/任务（35%）─────────────┐│
│          │ │对象+来源+真实下钻动作 │ │失败TU/未知/AI未启用        ││
│设置      │ └─────────────────────┘ └────────────────────────────┘│
│数据位置  │ 最近扫描 / 下一步                                           │
└──────────┴────────────────────────────────────────────────────────────┘
```

向导：标题 → 四步72px步骤栏 → 左表单65%/右构建摘要35% → 底部上一步与唯一下一步。第四步展示真实检查结果，不伪造全绿。

证据：标题/scan/Diff有效性 → 左38%搜索/复合筛选/40px对象行/分页，右62%身份/结论及按§7.6顺序的证据分组。独立滚动区显示总数/已显示/继续读取，不能top N冒充全部。

扫描中心：标题/身份/状态 → 阶段提示真实TU → 左阶段65%/右资源35% → 日志 → 固定操作区。无真实任务显示EMPTY及检查并扫描入口；历史归档不伪造正在扫描。

人工：组别计数 → 继续位置 → 共用证据分栏 → 固定三项决策/依据/声明确认者/独立处理状态 → 有序历史/冲突。导入：选择包→校验→来源与能力预览→原子提交→打开归档。
