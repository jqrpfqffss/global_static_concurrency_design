# 历史批次对比交互合同

补齐任务书7.10的“与基准对比”，沿用历史页、现有变量工作台和设计token。此功能读取已保存的归档，不执行Clang、不改变原Git Diff算法、不生成旧报告、不自动继承人工结论。实现及实际验收另列收据；本合同本身不是PASS证据。

| 动作/状态 | 可观察行为 |
|---|---|
| 选基准 | 历史行“设为对比基准”，始终显示完整批次ID；可更换。缺证据旧原件禁用。 |
| 选当前 | 其他行“与基准对比”；方向始终为基准→当前，同批次或不同工程拒绝。 |
| LOADING | 显示正在读取；禁止重入；分页成功前保留上一页及序号，读取失败可重试。 |
| VALID | 显示双方工程/目标/变体/覆盖/Git原始身份，以及事实、报告、来源根摘要。构建配置差异明确提示，不宣称源码当前有效。 |
| 对象变化 | 仅按完整canonical symbol_id关联；分为本轮新增、本轮未观察到、归档证据指纹相同、证据变化需核对。完整事实或报告任一变化时，对所有共有对象保守标记变化；不以名称或分类相同判定证据相同。 |
| 分页/检索 | 服务端总数/分类计数、字面搜索/变化类型筛选、50项分页；不下载完整facts/report。 |
| 查看详情 | 每行可打开基准或当前的同一canonical对象，复用变量工作台读取完整证据；不可用侧禁用。双方静态原始类别分别显示，AI/人工不混入静态分类。 |
| FAILED/缺证据 | 保留原归档，不反馈对比成功；缺证据旧原件、未发布任务或损坏身份明确拒绝。 |
| 返回 | 返回原历史检索/分页，基准仍可见；切换数据根不混用选择。 |

“本轮未观察到”不能显示为“已修复”；证据相同仅说明归档事实/报告指纹一致，不能关闭G1、替代真实输入/构建可比性或自动继承人工确认。完整相关证据仍在双方原库按需查询；此处不把分类对照宣称为严格全字段G1验收。
