## 实测发现并修复的问题

1. 目录行在进入子目录后被替换，焦点丢失，Alt+方向键无法连续导航。补上目录列表焦点恢复和整窗口快捷键转发后，原失败路径完整复测通过。
2. 任务日志仍因 flex 收缩出现内外两个纵向滚动框。现在仅日志正文滚动，资源详情独立显示，分页按钮固定可见；1366下正文276px，外层无纵向溢出。
3. 大型 TU 统计被 SQLite 选择为先扫描整张 `edge_child` 索引，页面长期停在读取中。保持谓词、完整集合和 DISTINCT 口径，只用 CROSS JOIN 固定从变量→TU列表的查询顺序。全部380文件、128426关联与独立逐变量计数完全相同，实际统计0.36秒；真实浏览器重新打开50条TU及右侧完整证据通过。详见[逐项计数对照](acceptance/workspace-v82-tu-counts.json)。原查询未得到完成耗时，不报告虚构加速倍数。
4. 测试脚本首次误把装饰箭头当作目录的无障碍名称，另一次在大型读取完成前断言列表存在；这些脚本失败与上述产品故障分开保留，不能作为产品通过证据。

5. 最终代码复查发现筛选失败、历史导出失败或资源轮询失败的提示可能被当前弹窗遮住。v83 将错误同步到活动窗口；注入明确 HTTP 503 后实际显示、重试清除通过，未伪造成功结果。见[弹窗失败验收](acceptance/workspace-v83-dialog-errors.json)。
