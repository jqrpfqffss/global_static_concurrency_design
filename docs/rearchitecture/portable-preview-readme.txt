ECRA Studio 开发预览（本版本尚未通过完整重构发布门禁）

双击 ECRA.cmd 打开本地中文工作台。已内置 Python 3.10.9、后端依赖和网页资源，查看归档无需安装 Node 或系统 Python。

当前可用：四步工程配置、真实SQLite扫描/安全停止/校验TU缓存恢复、进程树资源预算、双向调用树、归档代码行定位、复合筛选、可选OpenCode任务/技术收据、人工确认与撤销审计、跨扫描需重新确认、完整包/人工增量、安全清理预览/隔离/恢复/二次确认释放。
当前未完成：dirty字节隔离、全局外存求解、旧格式GUI流式归一化导入，以及全部U01–U24/G1–G8验收。三类大型原生工程、32GB Windows、干净离线机、系统DPI和独立工程师盲测未通过。
不要把本预览当作完整扫描器发布，不要删除旧结果和人工历史。

数据默认保存在 %LOCALAPPDATA%/ECRAStudio/data，与安装目录独立。
如需其他盘：ECRA.cmd --data-root D:/ECRAStudioData
升级只替换软件目录，不覆盖数据根。

关闭启动窗口或按 Ctrl+C 停止服务。浏览器标签关闭不会结束前台启动窗口。
CLI显式参数仍可调用，例如 ECRA.cmd doctor --config 配置路径。run默认独立数据根和SQLite；仅显式--legacy-output兼容验证会写旧报告，不用于日常新扫描。
完整预览操作说明见 STUDIO-GUIDE.md，旧 CLI 说明见 CLI-README.txt。

归档证据不等于当前源码重新验证；人工确认者是可编辑声明，未经身份认证。静态、AI与人工结论相互独立。
