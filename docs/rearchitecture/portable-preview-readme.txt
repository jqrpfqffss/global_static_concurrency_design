ECRA Studio 开发验收候选（完整重构发布门禁尚未通过）

双击 ECRA.cmd 打开本地中文工作台。内置Python3.10.9、后端依赖、离线页面和真实教学归档；查看结果无需系统Python、Node、固件或外部工具链。

首次可新建工程、导入历史结果或打开示例。工程向导支持真实目录选择、构建参数、main/ISR/任务入口及Git版本；日常可从首页重扫。任务中心提供真实扫描、停止与输入校验后的TU缓存恢复。变量工作台、归档源码、人工确认/撤销、标准包与增量分享均使用真实数据。

示例来自仓库代码的2TU实际ARM对象编译/Clang扫描；未链接固件、未验板，不代表用户工程。程序内资产只读，打开后保存在工具的 workspace 中；重复打开保留确认。

请把整套工具解压到非 C 盘可写目录，例如 D:\ECRA。数据默认位于解压根目录的 workspace，可从 Studio 的“工具数据目录”打开。自选的数据根必须位于 workspace/data-roots 内。移动或升级时保留完整 workspace。AppData 旧数据按 docs/workspace-storage.md 只读迁移，校验后再由用户决定清理。
