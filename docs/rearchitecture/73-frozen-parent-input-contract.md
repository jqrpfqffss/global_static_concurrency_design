# R2b：父进程读取同一冻结输入的合同

本子阶段承接R2a；正式dirty及恢复门禁继续保留，不增加用户配置开关或假可用按钮。

1. `InputSnapshot`以显式内部文件视图读取、记录和选择源码，默认路径逐项保持原行为。实际读取仍按原输入的逻辑路径记录完整哈希/大小/次数，不能为旧SAFE切换到新实时字节。
2. 冻结视图中的父读取只接受文件清单内原始字节；元数据/文件/候选集合变化保守失败。文件选择使用冻结的物理副本映回原逻辑路径，保持原glob及歧义语义，不能从原工程回退读文件。
3. 源码空目录也会影响候选集合，必须独立记录、复制和验证目录身份。新版捕获增加目录表；原版本仅文件的捕获仍可按原合同验证，但不能充当目录完整的父读取证明。
4. 证明声明存入输入闭包和诊断；当前正式恢复若遇新冻结父读取闭包，须明确拒绝未实现的恢复，不能忽略该声明后读取实时源码。
5. 单文件配置/响应文件及编译数据库必须可固定，不通过复制整个活跃数据根凑闭包；父/Worker与归档均核对同一身份。外部目录仍完整复制以保持正负探针。

验收包括真实父读取、汇编向量/map候选、CRLF/编码、原输入后来变化、复制品或目录篡改、缺声明拒绝、旧捕获兼容与原默认扫描回归。正式CLI/Git current、构建探针、外置CMake、扩大闭包/缓存/完整Diff仍需独立实测后接入，不由本子阶段自动解锁。
