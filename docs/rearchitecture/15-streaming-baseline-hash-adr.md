# ADR-014：原版完整JSON的只读有界比较工具（实施前合同）

原版INAV完整JSON保留于独立备份。将共享池JSON转换为完整SQLite图的诊断任务已运行数小时；它不是新扫描或标准归档，不得作为G4收益。保留该任务及所有原文件，另做只读的开发验收工具，避免G1比较必须先生成第二份巨型权威图。

工具逐个标量/容器解析原JSON，按现有ECRA_ORDERED_TYPED_V1规则计算完整有序类型摘要。共享池只保留磁盘上的固定大小摘要及有界LRU，不恢复完整事实；容器边临时顺序落盘，按原顺序散列，无排序、截断或采样。重复键、非法共享引用、前向引用、非有限浮点、无效完整报告结构和尾部额外内容必须拒绝。

同时计算不透明原值与现有compare_native_graphs.py的全部精确规范化作用域；仅原合同的顶层运行包络、finding复核字段/status、workspace.results_root和consumed_inputs行的两个read时间可规范化。相似名字、其他层级、类型、字段顺序、数组顺序和重复次数全部保留。原JSON本身、完整raw SHA及其只读备份就是原始包络证据，不删除或重写被规范化字段。

独立对照现有GraphWriter/NormalizedGraph及真实F030原版完整JSON，必须得到相同原/规范摘要；加入共享节点被多种作用域引用、超LRU、重复键外存检查、坏引用/形状、标量精度和允许/禁止差异测试。大输入前后SHA/大小/mtime必须不变。候选scan.db仍需完整深校验，事实及规范report摘要全等才可通过比较。

该工具仅用于开发验收，不更改正式持久化/分析/导入。摘要不相同时只能判FAIL；本工具不提供最早差异路径，随后可使用原完整图比较器定位。它不能单独证明输入闭包、三工程G2、32GB/G3或磁盘G4。大型比较在未实际运行前仍NOT_VERIFIED。

实际专项13项3.954秒PASS；8个作用域与独立GraphWriter/NormalizedGraph相同，覆盖有序类型/大整数/负零/代理字符、跨作用域共享池、超LRU和重复键落盘、坏引用/形状、精确规范化与输出路径污染拒绝。首轮测试fixture错用body-only Plan.dumps、并把非报告根交给业务投影，FAIL原日志保留；已改用原完整共享写入器和独立图编码器。真实F030原版JSON直接得到facts49e91182...与规范report62fd77e0...，与原完整图相同且原字节/mtime未变。见native-json-hashes-v1.json；大型工具尚未运行，不能标G1通过。v15运行时不变，此开发工具不在v15冻结中。
